# Промпт: тест за підручником у PDF

Цей промпт перетворює сторінки підручника на готовий файл тесту для Knowledge Tester. Працює з будь-яким чат-асистентом, який уміє читати PDF (Claude, ChatGPT, Gemini тощо).

## Як користуватися

1. Відкрийте новий чат з ШІ і **прикріпіть PDF** підручника. Якщо файл великий (понад 30–50 МБ або сотні сторінок), прикріпіть лише потрібний розділ: асистент читає уважніше, коли зайвого немає.
2. Скопіюйте весь промпт із сірого блоку нижче, заповніть рядки в розділі «ПАРАМЕТРИ ТЕСТУ» (те, що в квадратних дужках) і надішліть.
3. Збережіть відповідь у файл `test.json` (або просто скопіюйте текст).
4. У Knowledge Tester: **Тести → Імпортувати тест**, вставте текст або виберіть файл, натисніть **Перевірити тест**, далі **Створити тест**.
5. Якщо імпорт показав помилки, скопіюйте вміст поля «Скопіюйте для ШІ» назад у той самий чат і напишіть: «Виправ і надішли весь файл ще раз».
6. **Перечитайте тест перед уроком** (кнопка «Попередній перегляд»). ШІ помиляється: трапляються питання з двома правильними відповідями або з фактом, якого в підручнику немає. Для швидкої перевірки скористайтеся запитом «Ключ» з кінця цієї сторінки.

Сторінки вказуйте **за номерами сторінок PDF-файлу** (ті, що показує програма перегляду), а не за надрукованими в книжці: вони часто не збігаються.

## Промпт

````text
Ти досвідчений учитель і методист. За сторінками підручника, який я додаю до цього повідомлення (PDF), склади тест для програми Knowledge Tester.

ПАРАМЕТРИ ТЕСТУ
- Предмет і клас: [Історія України, 7 клас]
- Що перевіряємо: [§ 12 «Київська держава за Ярослава Мудрого», сторінки 84–91 PDF-файлу]
- Кількість питань: [12]
- Час на тест, хвилин: [15]
- Мета: [поточна перевірка після уроку]
- Відкриті питання (перевіряє вчитель вручну): [не більше одного]
- Додаткові побажання: [немає]

ЗВІДКИ БРАТИ ЗМІСТ
1. Використовуй лише матеріал указаних сторінок доданого PDF. Не додавай фактів, яких там немає, навіть якщо вони правильні.
2. Якщо ти не можеш прочитати ці сторінки (скан без розпізнаного тексту, не той файл, таких сторінок немає), не вигадуй тест. Замість JSON напиши одним реченням, що саме не так.
3. Учень під час тесту підручника не бачить. Не посилайся на «малюнок 3», «таблицю на с. 86», «вправу 214» чи «текст параграфа»: усе потрібне для відповіді має бути в самому питанні.
4. Не переписуй речення з підручника дослівно з пропущеним словом. Формулюй питання своїми словами, щоб перевіряти розуміння, а не зорову пам'ять.
5. Терміни, позначення й написання власних назв бери з підручника.

РІВНІ СКЛАДНОСТІ
- Приблизно 40 % питань: відтворення (факти, терміни, дати, означення). 1 бал.
- Приблизно 40 % питань: розуміння і застосування (пояснити причину, порівняти, розв'язати типову задачу, знайти помилку). 2 бали.
- Приблизно 20 % питань: аналіз (зробити висновок, поєднати кілька фактів, розв'язати нестандартну задачу). 3 бали.
Розташуй питання від простіших до складніших.

ТИПИ ПИТАНЬ (використовуй лише ці п'ять)
Орієнтовно: половина питань single_choice, решта порівну multiple_choice або choose_n та short_answer, відкритих стільки, скільки вказано в параметрах.
1. single_choice: 4 варіанти, рівно один правильний.
2. multiple_choice: 5 варіантів, 2 або 3 правильні. Учень не знає, скільки їх.
3. choose_n: учень має вибрати рівно n варіантів, і рівно n варіантів правильні. У тексті питання назви це число («Оберіть два…»).
4. short_answer: учень вписує відповідь сам, програма перевіряє автоматично. Підходить лише тоді, коли відповідь є одним словом, числом, датою або словосполученням до трьох слів. У "accept" перелічи всі прийнятні написання: синоніми, варіант з ініціалами і без, число цифрами і словом. Регістр літер, зайві пробіли, вид апострофа і крапку в кінці програма ігнорує сама. Для числових відповідей додай "mode": "numeric" (у "accept" тоді лише числа; одиниці вимірювання назви в тексті питання, а не у відповіді).
5. open: розгорнута відповідь, яку оцінює вчитель. Додай "rubric": за що саме нараховується кожен бал.

ВИМОГИ ДО ВАРІАНТІВ ВІДПОВІДЕЙ
- Неправильні варіанти мають бути правдоподібними: це типові помилки учнів, а не випадкові чи жартівливі відповіді. У задачах з обчисленнями це результати типових помилок (переплутаний знак, пропущена дія).
- Усі варіанти одного питання схожі за довжиною і стилем. Правильний не має бути найдовшим чи найдокладнішим.
- Не використовуй «усі відповіді правильні», «жодна відповідь не правильна», «правильні А і В».
- Уникай заперечень у питанні. Якщо без заперечення не обійтися, напиши його великими літерами: «Що НЕ належить до…».
- Одне питання не має підказувати відповідь на інше.
- Жоден неправильний варіант не можна обґрунтовано вважати правильним.

ОФОРМЛЕННЯ ТЕКСТУ
- Лише звичайний текст: без Markdown, LaTeX і HTML. Формули записуй у рядок: x^2, 3/4, √16, 2·3, H2O, 10 м/с.
- Програма не показує зображень. Не став питань, для яких потрібні карта, схема, графік чи малюнок.
- Лапки всередині тексту став «ялинками», щоб не зламати JSON.

ФОРМАТ ВІДПОВІДІ
Відповідай одним файлом JSON (або одним блоком коду з JSON), без жодних пояснень до чи після. Структура файлу точно така (тут по одному прикладу кожного типу питань):

```json
{
  "format": "knowledge-tester/test",
  "version": 1,
  "test": {
    "title": "Київська держава за Ярослава Мудрого (7 клас)",
    "description": "§ 12, с. 84–91.",
    "language": "uk",
    "settings": {
      "time_limit_minutes": 15,
      "shuffle_questions": true,
      "shuffle_options": true,
      "show_result": "score",
      "max_attempts": 1
    },
    "taker_fields": [
      { "key": "name", "label": "Прізвище та ім'я", "required": true }
    ],
    "grading": { "scale": "ua_12" },
    "questions": [
      {
        "type": "single_choice",
        "text": "У якому році Ярослав Мудрий став київським князем?",
        "points": 1,
        "options": [
          { "text": "988" },
          { "text": "1019", "correct": true },
          { "text": "1054" },
          { "text": "1113" }
        ]
      },
      {
        "type": "multiple_choice",
        "text": "Що з переліченого було збудовано в Києві за князювання Ярослава Мудрого?",
        "points": 2,
        "options": [
          { "text": "Софійський собор", "correct": true },
          { "text": "Десятинна церква" },
          { "text": "Золоті ворота", "correct": true },
          { "text": "Успенський собор Печерського монастиря" },
          { "text": "Михайлівський Золотоверхий собор" }
        ]
      },
      {
        "type": "choose_n",
        "text": "Оберіть дві держави, з правителями яких Ярослав Мудрий поріднився через шлюби своїх дочок.",
        "points": 2,
        "n": 2,
        "options": [
          { "text": "Франція", "correct": true },
          { "text": "Візантія" },
          { "text": "Норвегія", "correct": true },
          { "text": "Болгарія" },
          { "text": "Хозарський каганат" }
        ]
      },
      {
        "type": "short_answer",
        "text": "Як називався перший писаний збірник законів Київської держави?",
        "points": 1,
        "accept": ["Руська правда", "Руська правда Ярослава", "Правда Ярослава"]
      },
      {
        "type": "short_answer",
        "text": "Скільки років князював у Києві Ярослав Мудрий, якщо він посів престол 1019 року і помер 1054 року? Запишіть число.",
        "points": 2,
        "mode": "numeric",
        "accept": ["35"]
      },
      {
        "type": "open",
        "text": "Поясніть, чому князя Ярослава називають Мудрим. Наведіть щонайменше два приклади його діяльності.",
        "points": 3,
        "rubric": "1 бал: названо перший приклад (закони, будівництво, освіта, шлюбна дипломатія тощо). 1 бал: названо другий приклад. 1 бал: пояснено, як ці дії зміцнили державу."
      }
    ]
  }
}
```

Правила формату:
- "title": тема і клас. "description": параграф і сторінки. "time_limit_minutes": час із параметрів.
- Поля "settings", "taker_fields", "grading" залиш такими, як у прикладі (зміни лише час).
- Не пиши поле "id": програма створить їх сама.
- "points": 1, 2 або 3 за рівнем складності.
- "correct": true став лише на правильних варіантах; на неправильних це поле не пиши.
- Правильні варіанти мають стояти на різних місцях, не завжди першими.
- Валідний JSON: подвійні лапки, без коментарів, без коми після останнього елемента.

ПЕРЕД ВІДПОВІДДЮ ПЕРЕВІР (мовчки, не пиши про це)
- Кожну правильну відповідь можна підтвердити конкретним місцем на вказаних сторінках.
- У single_choice рівно один правильний варіант; у choose_n правильних рівно n.
- Кількість питань і час відповідають параметрам.
- У тексті немає посилань на малюнки, таблиці й номери вправ.
- JSON валідний.
````

## Корисні запити після цього

Надсилайте їх у той самий чат.

**Ключ (перевірка змісту перед уроком):**

```text
Покажи ключ до цього тесту таблицею: номер питання, правильна відповідь, сторінка PDF і коротка цитата з підручника, яка це підтверджує. Якщо для якогось питання цитати немає або можливі дві правильні відповіді, познач це окремо. Сам файл не змінюй.
```

**Виправлення після перевірки:**

```text
У питанні 7 правильними можна вважати два варіанти. Заміни неправильний варіант «…» на інший і надішли весь файл JSON ще раз.
```

**Другий варіант (щоб сусіди по парті мали різні тести):**

```text
Склади варіант 2 цього тесту: ті самі сторінки, та сама кількість питань, типи й рівні складності, але інші питання. У "title" додай «Варіант 2». Надішли окремим файлом JSON у тому самому форматі.
```

**Помилки під час імпорту:**

```text
Програма не прийняла файл. Ось її повідомлення:
[вставте вміст поля «Скопіюйте для ШІ»]
Виправ і надішли весь файл JSON ще раз.
```

## Поради

- **Сканований підручник.** Якщо PDF складається з фотографій сторінок без текстового шару, асистент може читати його з помилками (особливо формули й дати). Запит «Ключ» це покаже: цитати будуть неточними.
- **Математика, фізика, хімія.** Програма не показує формул і малюнків, лише текст у рядок. У «Додаткових побажаннях» напишіть, наприклад: «задачі лише з цілими відповідями», «без геометричних малюнків».
- **Мови.** Для short_answer у «Додаткових побажаннях» вкажіть, чи важливе точне написання: «відповідь вважається правильною лише без орфографічних помилок».
- **Оцінювання.** У файлі стоїть 12-бальна шкала (`ua_12`): оцінка рахується з відсотка набраних балів рівними проміжками. Якщо у вашій школі інші межі, змініть шкалу в налаштуваннях тесту після імпорту.
- **Розмір.** Найкраще виходять тести на 10–20 питань за один параграф. Для підсумкової контрольної з кількох тем зробіть окремі запити за темами й попросіть об'єднати питання в один файл.
- Формат файлу описано в [exchange-format.md](../exchange-format.md); англомовний промпт без підручника є в [create-test.prompt.md](create-test.prompt.md).
